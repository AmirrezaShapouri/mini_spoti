# Mini Spoti

Mini Spoti is a Django-based music library and streaming-style web
application inspired by Spotify. It was developed as a Django course
final project.

## Features

- User registration, login, and logout
- Browse songs, artists, and albums
- Song, artist, and album detail pages
- Search songs, artists, and albums
- Play uploaded audio files using the web audio player
- Track song play counts
- Add and remove favorite songs
- View a personal favorite songs page
- Django admin management for music content
- Responsive dark UI inspired by Spotify

## Tech Stack

- Python
- Django
- SQLite for local development
- HTML, CSS, and JavaScript
