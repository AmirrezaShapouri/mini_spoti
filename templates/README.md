# Mini Spoti Frontend

Static English frontend for a simple Spotify-inspired Django music platform.

## Included pages

- base.html
- home.html
- songs.html
- song-detail.html
- artists.html
- artist-detail.html
- albums.html
- album-detail.html
- favorites.html
- search.html
- login.html
- register.html

## Static files

- static/css/style.css
- static/js/app.js
- static/images/album-placeholder.svg
- static/images/artist-placeholder.svg

## Notes

The HTML files intentionally contain no Django template tags or template variables.
They use static sample data so the backend can be implemented manually for the exam.

Later, replace sample content with Django context variables and template syntax yourself.
